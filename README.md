## Animal Identification Tool

https://a4-charlottedugaw.onrender.com/ 

This is a React flip of my Assignment #2, a humorous animal identification tool. 

React feels like it hindered development here, just because the code I was working from was so strongly intertwined with the standard HTML/Javascript script. I can imagine a version of the app designed with React from the ground up that's both much less frustrating to put together and results in much prettier code, but I was kinda stubborn in reusing my old code. As a result, development sorta felt like a square-peg-round-hole situation.
